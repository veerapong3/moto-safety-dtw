# คู่มือการกรอกแบบฟอร์ม MOTO-Safety (สำหรับนักเรียน)

ใช้ประกอบหน้าเว็บ `/guide` — อ่านก่อนลงทะเบียนเพื่อลดการกรอกผิด

## ก่อนเริ่ม

1. เตรียมบัตรนักเรียน เบอร์โทร และดูป้ายทะเบียนให้ชัด
2. ถ่ายรูปไว้ล่วงหน้า 3 รูป: รถทั้งคัน / ป้ายทะเบียน / ผู้ขับขี่
3. ถ้าไม่แน่ใจว่ารถลงทะเบียนแล้วหรือยัง ให้ตรวจที่หน้าแรกก่อน

## ส่วนที่ 1 — ข้อมูลส่วนตัวนักเรียน

| ช่อง | วิธีกรอก |
|------|----------|
| คำนำหน้า / ชื่อ / นามสกุล | เลือกคำนำหน้า แล้วพิมพ์ชื่อ–นามสกุลภาษาไทย |
| เลขประจำตัวนักเรียน | ตัวเลขเท่านั้น ห้ามช่องว่าง |
| ระดับชั้น / ห้อง | เลือกจากรายการในระบบ |
| เบอร์โทรศัพท์ | ตัวเลข 9–10 หลัก เช่น `0891234567` ไม่ใส่ขีด |

## ส่วนที่ 2 — ข้อมูลรถและการใช้งาน

| ช่อง | วิธีกรอก |
|------|----------|
| ยี่ห้อ / สี | เลือกให้ตรงกับรถจริง |
| หมายเลขทะเบียน | พิมพ์ติดกัน ไม่เว้นวรรค เช่น `กข1234` หรือ `1กพ4567` (มีเลขนำหน้าได้อีก 1 หลัก + พยัญชนะไทย 2–3 ตัว + ตัวเลข) |
| จังหวัด | เลือกจังหวัดบนป้ายทะเบียนจริง |
| หมวกนิรภัย | เลือก `มี` หรือ `ไม่มี` ตามจริง |
| ผู้ซ้อนท้ายประจำ | ถ้าไม่มี ให้เว้นว่างได้ |

## ส่วนที่ 3 — รูปหลักฐาน (ต้องครบ 3 รูป)

1. **รูปรถ** — ถ่ายทั้งคันให้เห็นชัด
2. **รูปป้ายทะเบียน** — อ่านตัวอักษร/ตัวเลขได้ชัด ไม่เบลอ
3. **รูปผู้ขับขี่** — หน้าตรง สวมหมวกได้ถ้ามี

รอจนสถานะครบ **3/3** ก่อนกดบันทึก

## จุดที่มักผิด

- ทะเบียนมีช่องว่าง → พิมพ์ติดกัน
- เบอร์มีขีด → ใส่เฉพาะตัวเลข
- รูปไม่ครบแล้วกดบันทึก → รออัปโหลดครบก่อน
- ทะเบียนซ้ำ → ตรวจที่หน้าแรกก่อน ถ้าระบบมีอยู่แล้วไม่ต้องลงซ้ำ

## หลังบันทึกสำเร็จ

กลับหน้าแรก แล้วพิมพ์เลขทะเบียนเดิมอีกครั้งเพื่อยืนยันว่าพบในระบบ
